# App visual polish

The approved Cuebooker concept board is the visual source of truth for workspace composition. Production screens should follow it closely unless a real workflow, accessibility, responsive or performance constraint requires a deliberate deviation.

Current polish rules:

- Desktop rail stays narrow and visually secondary.
- Main content starts close to the rail with a small consistent gutter.
- Bottom language/theme/settings/sign-out controls remain compact and secondary.
- Active navigation uses a restrained surface plus the Cuebooker accent, not a large filled lime block.
- Overview cards remain dense and glanceable.
- Supporting panels must maintain readable contrast in both Dark and Light.
- Existing booking, calendar, history, guided-tour and profile behavior is preserved while the visual system converges on the concept board.
